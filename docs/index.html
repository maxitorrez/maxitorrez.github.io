Checkout y medios de pago en e-commerce B2B

E-commerce B2B · Checkout y medios de pago

Experiencia laboral · confidencial
Problemática
El proceso de compra B2B combina reglas comerciales, medios de pago y servicios externos; un cambio en cualquiera de ellos puede cortar el flujo de pedidos.
Objetivo
Que cada cambio en el checkout llegue a producción con requerimientos claros y validado de punta a punta.
Solución
Relevamiento con negocio, documentación del flujo y sus reglas, criterios de aceptación verificables y validación funcional y de integración antes de cada entrega.
Mi participación
Análisis funcional, documentación, coordinación con desarrollo y QA, validación y seguimiento de incidencias.
Flujo
  1. Necesidad del negocio
  2. Relevamiento y reglas
  3. Documentación del flujo
  4. Desarrollo
  5. Validación funcional e integración
  6. Regresión y salida
Resultado
Flujos de compra documentados y cambios validados antes de llegar al cliente. Detalles bajo confidencialidad.
Tecnologías y herramientas
  • Magento / Adobe Commerce
  • Magento Admin
  • APIs REST
  • Postman
  • SQL
  • Jira

Integraciones de APIs y servicios

Integraciones · APIs y servicios

Experiencia laboral · confidencial
Problemática
Plataformas y servicios que intercambian información (pedidos, validaciones, consultas) necesitan contratos claros y un análisis rápido cuando algo falla.
Objetivo
Integraciones documentadas, verificables y con errores diagnosticables.
Solución
Documentación de APIs y procedimientos, validación de servicios con Postman (JSON, XML, OAuth 2.0), consultas SQL para contrastar datos y análisis de logs y comportamiento de los servicios.
Mi participación
Análisis de integraciones, documentación de APIs, pruebas de integración y diagnóstico de errores.
Flujo
  1. Contrato del servicio
  2. Documentación
  3. Prueba con Postman
  4. Contraste de datos con SQL
  5. Análisis de logs
  6. Corrección y re-prueba
Resultado
Contratos documentados y una forma repetible de validar y diagnosticar integraciones.
Tecnologías y herramientas
  • APIs REST
  • JSON
  • XML
  • OAuth 2.0
  • Postman
  • SQL

  4. Registro de incidencias

  6. Regresión

Entregas validadas con incidencias registradas y seguidas hasta su cierre.

Asistente inteligente de escritorio

En uso
Problemática
Quería un asistente siempre a mano que trabaje sobre mis proyectos sin abrir una terminal y sin gastar el plan de IA en charla trivial.
Objetivo
Una mascota de escritorio conectada a Claude Code, con voz, acciones seguras y control del consumo.
Solución
App Electron con voz local (activación, transcripción y habla), enrutador que manda la charla corta a un modelo local (Ollama) y el trabajo a Claude, política de permisos y panel de consumo.
Mi participación
Definición del producto, requerimientos y criterios de aceptación, diseño funcional y validación. Desarrollo asistido por IA (Claude Code) con TDD.
Flujo
  1. Voz o texto
  2. Enrutador local / Claude
  3. Aprobación si modifica algo
  4. Acción
  5. Respuesta hablada
Resultado
En uso diario. 341 pruebas automatizadas en verde y pruebas de humo contra los servicios reales.
Tecnologías y herramientas
  • Electron
  • Node.js
  • Claude Agent SDK
  • Ollama
  • Whisper
  • Piper

StorScrap

Producto digital · Extracción de datos de e-commerce

Prototipo funcional
Problemática
Conocer el catálogo y los precios de una tienda online exige revisar cientos de páginas a mano.
Objetivo
Extraer el catálogo completo de una tienda a una base de datos, con historial de precios, como servicio comercializable.
Solución
Adaptadores para Shopify, VTEX, WooCommerce y la API oficial de Mercado Libre; si no hay API, datos estructurados o un navegador real. Respeta robots.txt. Interfaz web con vista previa y planes.
Mi participación
Idea y modelo de negocio, requerimientos, criterios de aceptación, medición de cobertura y validación. Desarrollo asistido por IA con TDD.
Flujo
  1. URL de la tienda
  2. robots.txt
  3. ¿Plataforma con API?
  4. Extracción
  5. SQLite + historial
  6. Exportación CSV/JSON
Resultado
Prototipo funcional probado contra tiendas reales; cobro de membresías pendiente.
Tecnologías y herramientas
  • Node.js
  • SQLite
  • Playwright
  • APIs REST
  • JSON
