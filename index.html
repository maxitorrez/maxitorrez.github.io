Ares Asistente de escritorio con IA

Mascota animada para Windows conectada a Claude Code. Conversa por texto y por voz, ejecuta acciones con aprobación del usuario y muestra cuánto del plan se consumió. Las charlas cortas las responde un modelo local con Ollama, sin gastar el plan.

  • Voz local: activación con "Oye Ares" (Vosk), transcripción con Whisper y respuesta hablada con Piper.
  • Enrutador híbrido: Ollama para la charla y Claude para el trabajo, con derivación automática.
  • Política de permisos: toda acción que modifica algo pide aprobación.
  • 341 pruebas automatizadas y pruebas de humo contra los servicios reales.

Electron · Node.js · Claude Agent SDK · Ollama · Whisper · Piper · Vitest

Código privado: disponible a pedido.

StorScrap Extractor de catálogos de tiendas online

Recorre una tienda online y guarda su catálogo completo en SQLite: nombre, SKU, marca, categoría, precio, stock, imágenes y variantes, con historial de precios. Tiene línea de comandos e interfaz web con vista previa.

  • Adaptadores para Shopify, VTEX, WooCommerce y la API oficial de Mercado Libre; si no hay API, usa JSON-LD, microdata o un navegador real.
  • Respeta robots.txt, espacia las peticiones y se protege contra SSRF.
  • Exporta a CSV y JSON sin riesgo de inyección de fórmulas.
  • Pruebas unitarias, de integración contra tiendas falsas y E2E con Chromium.

Node.js · SQLite · Playwright · HTTP + SSE · Vitest

Código privado: disponible a pedido.
